# Política de Segurança

Não publique vulnerabilidades, senhas, arquivos de usuários ou dados da fábrica
em issues públicas.

Para relatar uma vulnerabilidade, abra uma discussão privada com o proprietário
do repositório no GitHub, descrevendo: versão afetada, impacto, passos de
reprodução e sugestão de correção. A confirmação será enviada assim que a
análise iniciar.

## Escopo prioritário

- autenticação e permissões;
- acesso à rede local;
- armazenamento de dados operacionais;
- importação de planilhas;
- IA local e credenciais opcionais.
