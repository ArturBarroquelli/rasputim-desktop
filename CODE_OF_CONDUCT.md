# Código de Conduta

## Nosso compromisso

Queremos uma comunidade técnica respeitosa, objetiva e segura para pessoas de
qualquer experiência, origem ou identidade.

## Conduta esperada

- Trate todos com respeito e foco no problema.
- Faça críticas sobre código e decisões, nunca sobre pessoas.
- Proteja dados de clientes, credenciais e informações da operação.
- Relate comportamentos inadequados de forma privada ao responsável pelo projeto.

## Conduta inaceitável

Assédio, discriminação, ameaças, exposição de dados, ataques pessoais ou envio
de conteúdo malicioso não serão aceitos.

## Aplicação

O responsável pelo projeto poderá editar, ocultar ou remover contribuições que
violem este código de conduta.
