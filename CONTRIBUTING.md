# Como contribuir

Obrigado por querer melhorar o Rasputim Tecnologis.

1. Abra uma issue descrevendo o problema ou a sugestão antes de iniciar uma mudança grande.
2. Crie uma branch com foco em uma única melhoria.
3. Execute `npm run verify` antes de abrir um pull request.
4. Explique o impacto operacional, os testes realizados e qualquer alteração de dados ou permissões.
5. Nunca envie bases de clientes, planilhas reais, senhas, tokens ou modelos proprietários.

O repositório é público para avaliação e colaboração. O uso, distribuição ou
exploração comercial do código depende de autorização prévia do autor, conforme
a [licença](LICENSE).
