# Rasputim Desktop

Compilação Windows do Rasputim v5.4 Cloud Lite, com janela própria baseada no
Microsoft Edge WebView2. O processo de compilação não recebe arquivos `.env`,
chaves de API, planilhas ou orçamentos.

O artefato produzido contém `Rasputim.exe`, o runtime oficial do Node.js e as
dependências necessárias. Extraia o ZIP inteiro e execute `Rasputim.exe`.
