# Modelos GGUF

Coloque aqui **um modelo `.gguf` compatível com `llama-server`**.

O Git ignora arquivos `.gguf` de propósito: modelos são grandes, mudam com frequência e não devem ser versionados junto do código-fonte.

O script `scripts/iniciar-ia-local.cmd` usa automaticamente o primeiro arquivo `.gguf` encontrado nesta pasta.
